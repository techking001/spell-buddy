Keyboard suggestion test

For the owner only. It is not linked from the app.

  1. Open this page on the phone your students use, with the keyboard they normally use.
  2. In each box below, type vege slowly.
  3. Look at the row above the keyboard. Does it show vegetable (or other words)?
  4. Choose an answer for each box, then press Make my report and send it to me.

Try each keyboard your students use (for example Gboard, Samsung Keyboard, SwiftKey, iPhone).
